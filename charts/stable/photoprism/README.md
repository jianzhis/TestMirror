# photoprism

## 介绍

PhotoPrism® 是一款适用于去中心化网络的 AI 照片应用。它利用最新技术自动标记和查找图片，不会妨碍您。您可以在家中、私人服务器或云端运行它。

## 主要功能

- Kubernetes 应用部署
- 资源限制和请求配置
- 环境变量配置
- 服务暴露配置

## 配置参数说明

| 参数名称                  | 描述         | 类型    | 默认值                |
| ------------------------- | ------------ | ------- | --------------------- |
| `replicaCount`            | 副本数量     | integer | 1                     |
| `image.repository`        | 应用名称     | string  | photoprism/photoprism |
| `image.tag`               | 应用标签     | string  | latest                |
| `image.pullPolicy`        | 应用拉取策略 | string  | IfNotPresent          |
| `resources.limits.cpu`    | CPU 限制     | string  | 1000m                 |
| `resources.limits.memory` | 内存限制     | string  | 1024Mi                |

## 部署步骤

1. 输入配置参数

2. 选择拥有足够配置应用空间

3. 立即部署

## 使用说明

PhotoPrism® 是一款现代化的 AI 照片管理应用，旨在为用户提供一种便捷的方式来组织和查找个人照片。它采用去中心化的架构，允许用户在自己的家中、私人服务器或云端中运行，从而保护用户的隐私和数据安全。

该应用利用先进的人工智能技术，对照片进行自动标记和分类，便于用户快速检索所需的图片。无论是日常生活中的点滴记录，还是特殊事件的珍贵回忆，PhotoPrism® 都能让用户轻松找到所需的照片。

此外，PhotoPrism® 还支持多种文件格式和大容量存储，满足用户对照片管理的各种需求。它的开源特性也使得开发者可以自由定制和扩展功能，适应不同用户的使用场景。无论是个人用户还是专业摄影师，PhotoPrism® 都是一个值得信赖的照片管理解决方案。

## 故障排除

1. Pod 无法启动

- 检查资源限制是否合理
- 检查应用是否存在且可访问

2. 服务无法访问

- 检查服务端口配置
- 检查 Pod 运行状态
